# ML Case Study - Linear Regression

Minimal project scaffold for:
- Exploratory Data Analysis (EDA)
- Data preprocessing
- Feature engineering
- Linear Regression modeling

## Structure

```text
.
|-- data/
|   |-- raw/
|   `-- processed/
|-- models/
|-- notebooks/
|-- reports/
|   `-- figures/
|-- src/
|   `-- __init__.py
|-- .gitignore
`-- requirements.txt
```

## Quick Start

1. Create and activate a virtual environment.
2. Install dependencies:
   - `pip install -r requirements.txt`
3. Put your original dataset in `data/raw/`.
4. Start EDA in `notebooks/`.
