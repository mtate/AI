# Click Prediction Case Study

Minimal project scaffold for an end-to-end click prediction analysis.

## Structure

- `data/` for raw and processed datasets
- `notebooks/` for EDA and analysis work
- `src/` for reusable code
- `reports/` for figures, summaries, and model outputs
- `models/` for saved model artifacts

## Workflow

1. EDA
2. Preprocessing
3. Feature engineering
4. Modelling
